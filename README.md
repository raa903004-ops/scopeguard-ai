# ScopeGuard AI

Локальное приложение для сверки клиентских запросов с договором. Интерфейс на английском. Проекты, текст договоров и история хранятся в IndexedDB текущего браузера.

## Запуск

Нужен Node.js 24. Выполните `npm ci`, затем `npm run dev` и откройте адрес Vite. Для проверок выполните `npm test`, `npm run lint`, `npm run typecheck` и `npm run build`.

## Работа

1. Откройте **Get early access** и создайте проект. Вставьте договор или импортируйте TXT либо PDF с текстовым слоем.
2. Введите запрос и ставку в USD. При первом запуске **Analyze locally** браузер скачает модель и среду выполнения. Нужны WebGPU и HTTPS либо localhost. Используется SmolLM3 3B с резервной Llama 3.2 1B. Обе модели используют q4f32 и работают без shader-f16. Для длинного договора можно указать дословный фрагмент через **Review a contract excerpt**. При недоступности модели используйте **Manual review**.
3. Проверьте решение, цитату и оценку часов. Цитата проверяется по исходному тексту, смысловое соответствие оценивает пользователь. Потенциальная доплата равна часам × ставке для работ вне договора. Ставка сохраняется вместе с проверкой.
4. **Generate client email** создаёт редактируемый черновик. В истории можно исправить выводы и выгрузить CSV. **Print / Save PDF** открывает отчёт проекта в диалоге печати. В **Settings** можно экспортировать проекты и историю в JSON и удалить данные рабочего пространства.

В рабочей области доступен учебный договор для запуска реального локального анализа. Учебные результаты не входят в статистику. Демо на главной использует три подготовленных вымышленных запроса. Кнопка раннего доступа сразу открывает бесплатную рабочую область.

## Cloudflare Pages

На бесплатном тарифе Pages подключите репозиторий, задайте Node.js 24, сборку `npm run build` и каталог `dist`. Для прямой загрузки после сборки выполните `npx wrangler pages deploy dist --project-name scopeguard-ai` в своём аккаунте. Конфигурация находится в `wrangler.toml`. Серверные функции, ключи API и платёжная система не требуются. [Настройки сборки Pages](https://developers.cloudflare.com/pages/configuration/build-configuration/)
